靜態道路硬體危險度評估系統

推廣行人安全與路口硬體維護！運用地端 AI 邊緣運算即時分析街景照片中的斑馬線狀況，守護市民過馬路安全。

核心 AI 辨識能力

1. 斑馬線精準偵測

採用 YOLO 深度學習模型，自動定位圖像中的斑馬線位置。標示框採用 綠色框 (#00FF00)，並附帶信心度百分比。

2. 標線狀態品質分析

即時裁切原圖標線區域，進行灰階階調與對比分析，評估標線是否磨損、褪色或清晰度不足。

3. 駕駛視角空間評估

針對駕駛前方視角照片，計算斑馬線於畫面底部距離與高度佔比，分析近端視線盲區與空間壓迫感。

4. 綜合風險分級報告

結合五項客觀指標加總評分，自動分類為低風險、中風險與高風險，並提供具體改善建議。

技術特色

  • 純地端隱私保護： 採用 ONNX Runtime Web，影像處理與 AI 推論 100% 在您的瀏覽器內完成，照片絕不上傳伺服器。
  • YOLO 空間標定： 自動將輸入影像進行 Letterbox 補邊縮放，維持比例不失真。
  • 動態評分決策引擎： 結合像素統計（Histogram）與幾何位置量測，提供客觀科學數據。

評估標準與權重說明

本系統針對最高信心度之斑馬線目標，依據以下五項指標計算總分（0~7 分）：

評估指標 檢測方式與標準 計分規則
1. 標線清晰度 裁切框內灰階 256 格直方圖，計算 P90 - P10 對比度 ≥80 (0分) | 50~80 (1分) | <50 (2分)
2. 框內能見度 框內區域之平均灰階值 (0~255) 70~200 (0分) | 40~70 或 200~230 (1分) | <40 或 >230 (2分)
3. 完整度 框邊緣距離影像四邊小於邊長 2% (邊緣裁切風險) 未貼近邊緣 (0分) | 貼近任一邊緣 (1分)
4. 視線盲區 限駕駛視角：底邊距離佔比 = (圖高 - (y+h)) / 圖高 ≥0.18 (0分) | <0.18 (1分)
5. 空間壓迫 限駕駛視角：斑馬線高度佔比 = h / 圖高 ≤0.25 (0分) | >0.25 (1分)

* 註：以上指標門檻均定義於前端程式最上方常數庫，可依宣導需求微調。

⚠️ 尚未支援之動態行為說明

本宣導站目前專注於「靜態道路硬體（斑馬線）」評估。以下項目未包含於目前模型的辨識範圍內：

  • 紅綠燈號誌辨識與號誌顏色判讀
  • 動態行人、車輛位置及過馬路行為偵測
  • 未禮讓行人、違規停車等違規行為認定
  • 機車駕駛與乘客未戴安全帽檢測

※ 上述功能需另外擴充 YOLO 多類別標註資料集與訓練模型方可支援。

🛠️ 系統開發與部署流程

  1. Roboflow 標註： 收集台灣道路街景照片，針對「斑馬線 (crosswalk)」進行 Bounding Box 標註與資料增強。
  2. Google Colab 訓練： 採用 Ultralytics YOLO26n 輕量化架構進行遷移學習，優化邊緣端執行效率。
  3. 模型轉檔 ONNX： 將訓練完成的權重匯出為 ONNX 格式 (best.onnx)，優化 Web 端加載。
  4. ONNX Runtime Web 推論： 透過純 JavaScript 於前端瀏覽器完成 Tensor 前處理、矩陣運算與 NMS 後處理。
